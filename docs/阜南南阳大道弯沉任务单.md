# 阜南南阳大道现场单据

## 目标

在“阜南南阳大道”项目中手工填写现场检测信息，一次打印两张关联单据：横向的现场检测任务单和纵向的现场取样单。

## 页面入口

左侧模板类别中的“阜南南阳大道”。页面只显示“现场检测任务单和现场取样单”入口，不再显示台账导入、Excel 粘贴和历史任务列表。

历史台账数据保留在数据库中，但不作为本功能的填写来源，也不会在页面中显示或删除。

## 填写和默认规则

1. 点击“填写现场单据”后手工填写任务编号、样品编号、取样数量、工程部位/用途、日期等信息。
2. 委托单位、工程名称、样品名称、规格、试验项目、标准、部门和下达人提供初始默认值。
3. 点击“确认并打印”后，本次所有填写内容保存在当前浏览器的这台电脑中。
4. 下次打开时，自动带出上一次保存的内容；可直接修改后再次打印。
5. 换一台电脑时，该电脑需要首次填写一次。浏览器清理本地数据后，也需要重新填写一次。

## 编号和数量联动

- 委托编号不在填写页面显示。任务编号修改后，系统自动将任务编号前两个字母替换为 `WT`，其余内容保持一致。
- 记录编号、报告编号不在填写页面显示。样品编号修改后，系统自动分别将样品编号前两个字母替换为 `JL`、`BG`，其余内容保持一致。
- 取样数量输入项显示为“取样数量（处）”，只输入数字；打印时自动在数字后显示“处”。
- 下达部门、接受部门、下达人、取样地点、取样人/见证人使用默认内容，不在填写页面显示。
- 委托单位、工程名称、工程部位/用途在第一行按三格显示；取样依据/方法与试验项目、执行标准同一行，按三格显示。
- 样品规格/型号使用内嵌按钮点选，默认 AC-13C；可选 AC-13C、AC-20C、4%、5%、10%，点击后高亮当前选项。
- 试验项目下方提供常用项目按钮：压实度（表干法）、压实度（灌砂法）、厚度（取芯法）、弯沉（落锤法）、渗水、摩擦系数（摆式仪法）、平整度（连续式平整度仪）、抗滑构造深度（铺砂法）。一次选择一个，点击后自动填入试验项目。

## 两张单据的关联

现场检测任务单与现场取样单共用样品规格、工程部位/用途、日期和取样依据/方法等字段，保证打印内容一致。

取样单一页内打印两份相同内容，并在底部保留共同取样说明。

## 打印规则

1. 第一页为横向 A4 的现场检测任务单。
2. 第二页为纵向 A4 的现场取样单：上边距为 22mm，左右表格有效宽度为 168mm；页面内两份表格保持规整，表内文字为 12pt、标题为 20pt。字号规则放在通用打印样式之后，防止被其它模板的字号覆盖。
3. 网页中的取样单预览同步采用打印版的页边距、行高和字号比例，便于打印前核对版式。
3. 点击“确认并打印”后先保存默认内容，再打开浏览器打印窗口。
4. 接受人、接受日期和备注保留空白，供纸质单据手写。
5. 网页中的现场检测任务单预览同步采用横向 A4 打印版的页面尺寸、边距、表格行高和字号比例，便于打印前核对。
