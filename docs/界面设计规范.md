# 恒信通界面设计规范

更新时间：2026-11-05

## 目标

恒信通是公司内部资料和业务工作台。界面首先保证资料好找、操作清楚、打印稳定，不做宣传网站式的大图、渐变和装饰卡片。

## 页面结构

1. 顶部为系统名称、当前登录人和全局操作。
2. 左侧为一级类别和二级分类，选中项使用浅绿色底色与深绿色文字。
3. 右侧为工作区，标题与筛选条件在上，资料表格或业务工具在下。
4. 预览、填写、上传和后台管理均使用居中弹窗，不遮挡打印内容。

## 视觉规则

- 主色：`#16406B`；悬停色：`#1F5A99`；按下色：`#103357`。
- 顶部栏统一使用白色背景和 `#E4E8EE` 底部分隔线，不再使用深色横幅。
- 背景：`#F4F7F8`；普通工作区：白色。
- 边框：`#DBE3E6`；圆角最多 6px。
- 不使用渐变背景、装饰性光斑或悬浮卡片叠卡片。
- 主要操作为实心绿色按钮；普通操作为白底细边框按钮；危险操作使用红色提示。
- 资料列表优先使用紧凑表格，表头浅灰，鼠标经过行使用浅绿色。

## 响应式规则

- 电脑端固定左侧导航，右侧展示完整表格。
- 手机端导航移到页面顶部，表格转为逐项资料卡片，搜索和筛选纵向排列。
- 打印单据不受本规范影响，继续使用各自的打印样式。

## 检测视频页面

- 检测视频使用无表头的课程列表，不使用传统资料表格。
- 每行以课程顺序、课程名称为主信息，讲师、更新时间和备注为辅助信息。
- 播放使用主色实心圆角按钮，下载使用白底细边框按钮，编辑为弱操作。
- 播放区域采用黑色影院背景，倍速控制使用居中的分段按钮。
- 手机端操作按钮换到课程信息下方，课程名称允许自然换行，不截断关键信息。

## 变更边界

本规范只约束非打印页面的视觉样式，不修改资料分类、上传下载权限、业务数据、表格字段或打印版式。
