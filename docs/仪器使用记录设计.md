# 仪器使用记录

## 目标

根据试验参数自动匹配仪器名称和设备编号，检测人员确认后保存使用记录，减少手工查找设备编号的工作量。

## 入口

左侧模板类别中的“仪器使用记录”，与委托单、检测报告、管理体系等一级类别并列。

## 匹配规则

1. 优先把输入的试验参数按逗号、顿号、分号和换行拆分。
2. 在仪器一览表的“试验参数”和“类别”字段中匹配。
3. 匹配结果显示仪器名称和设备编号，默认全部勾选。
4. 检测人员可以取消不需要的仪器后保存。
5. 参数匹配不到时，不自动猜测设备，提示检查参数或补充仪器对应关系。

## 自动填写和人工填写

自动填写：使用日期、样品编号、试验参数、仪器名称、仪器编号。

人工确认：开始时间、结束时间、使用人、使用前状态、使用后状态、备注。

## 数据来源

- `仪器名称及编号.xlsx`：仪器名称和编号基础表。
- `仪器名称及编号(1).xlsx`：仪器名称、编号与试验参数对应关系。
- `岩土室仪器使用记录.docx`：使用记录表格式参考。
- `温度 ℃、湿度 %RH (4).xlsx`：历史记录参考，不自动覆盖历史数据。

## 操作流程

1. 打开“仪器使用记录”。
2. 填写或粘贴试验参数，可填写样品编号和使用日期。
3. 点击“匹配仪器”。
4. 取消不需要的仪器，补充使用时间和使用人。
5. 点击“保存使用记录”。

当前版本先实现仪器匹配和记录保存。后续可从现场检测任务单自动带入样品编号、日期和试验项目，并增加打印版使用记录。
