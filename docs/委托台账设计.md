# 委托台账设计

记录日期：2026-07-28

## 目标

把委托单从“网页临时填写”升级为“后台正式登记”。

用户在填写委托单/任务单时，点击“正式登记并生成编号”，系统自动生成委托编号、任务编号和样品流水号，并写入数据库台账。

## 编号规则

委托编号格式：

```text
WT-年号-委托顺序号-工程代码
```

示例：

```text
WT-2026-0001-A06
```

含义：

- `WT`：委托开头拼音。
- `2026`：年号。
- `0001`：同一年、同一工程代码下的委托顺序号。
- `A06`：固定工程代码，对应固定工程名称。

任务编号格式：

```text
RW-年号-委托顺序号-工程代码
```

任务编号后三组必须与委托编号一致，只把第一组从 `WT` 改为 `RW`。

示例：

```text
RW-2026-0001-A06
```

## 样品流水号规则

样品流水号按以下条件分别顺延：

- 年号
- 工程代码
- 样品名称

例如同一工程 `A06` 下：

- 样品名称为“砂”：从 `0001` 开始顺延。
- 样品名称为“碎石”：也单独从 `0001` 开始顺延。

不同样品名称之间互不占用流水号。

## 自动带入规则

- 委托单位对应固定工程名称和工程代码。
- 接样日期默认同步委托日期。
- 接样人默认填写 `李晓东`。
- 室内检测任务流转单中的“下达人”同步为接样人。

## 数据表

后端新增 `entrust_records` 表，保存正式委托台账。

主要字段：

- 委托单位
- 工程名称
- 工程代码
- 委托编号
- 任务编号
- 样品名称
- 样品流水号
- 样品编号
- 记录编号
- 报告编号
- 委托日期
- 接样日期
- 接样人
- 委托人
- 下达部门
- 接受部门
- 工程部位/用途
- 备注
- 登记人
- 登记时间

## 操作流程

1. 打开委托单/任务单模板，点击“填写”。
2. 选择委托单位、样品名称和委托日期。
3. 点击“正式登记并生成编号”。
4. 系统写入后台台账，并把正式编号回填到委托单和任务流转单。
5. 需要查看历史时，点击“刷新台账”。
6. 需要导出时，点击“导出台账”，导出 CSV 文件，可用 Excel 打开。

## 当前边界

当前第一版导出为 CSV，不是真正的 xlsx 文件。

原因：项目目前没有 Excel 生成依赖，CSV 对现有项目影响更小，也能直接用 Excel 打开。后续如果需要带格式、合并单元格、固定列宽，再升级为 xlsx。
