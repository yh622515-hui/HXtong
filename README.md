# 恒信通使用说明

## 访问地址

本机访问：

```text
http://localhost:3000
```

同事在同一局域网访问：

```text
http://192.168.60.182:3000
```

## 账号安全提醒

第一次正式使用前，请用初始管理员账号登录后，马上到“管理后台”的用户管理里修改账号和密码。

如果是在一台新电脑上第一次运行，系统会在本机生成：

```text
data\initial-accounts.txt
```

打开这个文件，可以看到第一次登录用的临时账号密码。

如果已经改过账号或密码，以后台里现在显示的实际人员账号为准。不要把正式使用的账号密码写到 GitHub 或公开文档里。

## 怎么启动

双击：

```text
start.bat
```

看到窗口里显示访问地址后，就可以打开浏览器访问。

注意：启动窗口不要关。关掉窗口后，系统就停止。

## 怎么停止

双击：

```text
stop.bat
```

它只会停止占用 3000 端口的服务。

## 文件放在哪里

数据库：

```text
E:\恒信通\data\hengxintong.db
```

上传的 Word/PDF：

```text
E:\恒信通\uploads
```

手动备份：

```text
E:\恒信通\backup
```

## 第一版已包含

1. 登录。
2. 登录页注册普通用户。
3. 普通用户查看和下载。
4. 管理员上传 Word/PDF/Excel。
5. 管理员替换旧模板。
6. 模板分为委托单/任务单模板、检测报告模板、管理体系。
7. 分类按模板类型分开管理。
8. 备注编辑。
9. PDF 在线预览，Word/Excel 下载查看。
10. 上传记录、下载记录、最后下载人、最后下载时间。
11. 权限分为普通用户、管理员、超级管理员。
12. 超级管理员可以新增用户、改账号、改姓名、改密码、改权限、启用停用。
13. 空分类可删除；已有模板或下级分类的分类不能直接删除。
14. 管理员和超级管理员可以手动备份数据库和上传文件。
15. 委托单/任务单模板里已有“填写”样品，可下拉选择、手动改字、打印预览。
16. 管理员和超级管理员可以查看操作日志。
17. 模板可以停用和恢复；停用不删除文件，只是从普通列表隐藏。
18. 备份会记录到数据库，备份内容包含数据库和上传文件夹。
19. 模板有历史版本；替换和恢复都会留下版本记录，可以恢复旧版。
20. 首页有提醒卡片，可快速看模板总数、缺 PDF、未下载过、最近更新。
21. 搜索改为输入后点放大镜确认，并增加文件类型和状态筛选。
22. 可以导出模板清单，WPS/Excel 可直接打开。
23. 管理后台可以查看备份列表，并恢复指定备份；恢复前会自动备份当前状态。
24. 已配置 Windows 开机自动启动；电脑登录后会自动启动恒信通。

## 停用和恢复模板

模板列表里点“停用”，模板会从普通列表隐藏，但文件仍然保留在 `uploads` 文件夹里。

需要恢复时，进入“管理后台”，在“已停用模板”里点“恢复”。

## 操作日志

管理员和超级管理员登录后，顶部有“操作日志”按钮。

操作日志会记录上传、替换、下载、停用、恢复、分类修改、用户修改和备份等动作。

## 历史版本

模板列表里点“版本”，可以看到 Word、PDF、Excel 的历史版本。

管理员和超级管理员可以点“恢复此版”。恢复旧版不会删除当前新版，当前新版仍会留在历史版本里。

## 首页搜索和导出

搜索框输入内容后，点放大镜按钮确认搜索；回车也可以搜索。

文件筛选可以按 Word、PDF、Excel、缺 PDF 查看。

顶部“导出清单”会下载模板清单，包含名称、分类、上传人、最后下载人、备注等信息。

## 恢复备份

进入“管理后台”的“安全维护”，可以看到可恢复备份列表。

点“恢复此备份”后，系统会先自动备份当前状态，然后用选中的备份覆盖数据库和 uploads 文件夹，并自动重启网站。

恢复完成后，等待约 10 秒，重新打开网站并登录。

## 开机自动启动

已经在 Windows 启动文件夹里创建快捷方式：

```text
恒信通自动启动.lnk
```

它会执行：

```text
E:\恒信通\hxt-autostart.ps1
```

脚本会先检查 3000 端口是否已经有服务运行；如果已经运行，就不会重复启动。

如果以后要取消开机自动启动，删除这个快捷方式即可：

```text
C:\Users\Administrator\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\恒信通自动启动.lnk
```

## 权限说明

普通用户：查看、预览、下载。

管理员：普通用户功能，加上传、替换、备注、分类管理、备份。

超级管理员：管理员功能，加人员账号管理。

## 上传文件名

以后新上传或替换的文件，会按报告名称保存到 `uploads` 文件夹，例如：

```text
报告名称-Word.docx
报告名称-PDF.pdf
报告名称-Excel.xlsx
```

如果同名文件已经存在，系统会自动加编号，避免覆盖旧文件。

## 关于好记地址

现在同事访问地址是：

```text
http://192.168.60.182:3000
```

如果想改成：

```text
http://hengxintong:3000
```

需要让办公室路由器或公司网管设置一条内网名字：

```text
hengxintong -> 192.168.60.182
```

如果没有网管，也可以在每台同事电脑上单独设置，但每台电脑都要改一次。

如果想改成不带端口的：

```text
http://hengxintong
```

还需要把系统端口从 `3000` 改成 `80`，并检查 Windows 防火墙和端口占用。

## 重要提醒

这套系统只建议在公司局域网内部使用，不要直接放到公网。

如果电脑重启，需要重新双击 `start.bat` 启动。
